MSXTRACK

An all-in-one chiptune and sound-effect tracker that runs on the MSX itself. It's a 16KB cartridge for every MSX1, MSX2, MSX2+ and turbo R with 16KB of RAM or more.

What it does

  • Pattern editor: 3 PSG channels, up to 64 rows, piano-key note entry, copy/paste, transpose, undo/redo and jam mode.
  • 16 effects: arpeggio, slides, portamento, vibrato, volume slide, hardware envelope, noise, delay, cut, detune, speed, jump and break.
  • Instruments and sound effects: 16-step sequences of volume, arpeggio, pitch sweep, noise and tone/noise/envelope switches, with loops. 15 presets, including kick, snare, laser, explosion and coin.
  • Song editor: 128-position order list, speed, pattern length and loop point.
  • Saving: disk (when a drive is present) and tape, with a warning before unsaved work is lost.
  • Runs everywhere: only BIOS calls and the standard PSG ports, so it works on any keyboard layout, any slot layout, and the original BIOS or C-BIOS.

Getting started

The tracker starts with a demo song. Press RETURN to hear it and F5 for the built-in help.

KeysAction
F1 – F5Pattern, song, instrument, file, help
Z S X D C V G B H N J M / Q 2 W 3 E R 5 T 6 Y 7 U IPiano (two octaves)
SPACE / RETURN / ESCPlay pattern / play song / stop
CTRL+Z · CTRL+JUndo · jam mode (keys only play)
CTRL+N · CTRL+BNew position with an empty pattern · with a copy of this one

Use your songs in games

mtkplay.asm is a replayer of about 2.3KB that you include in your own program. It uses the tracker's own engine, so songs sound the same as in the editor. Songs can stay in ROM, and one sound-effect voice can play over the music.

MTK_RAM equ 0E000h        ; 175 bytes of RAM
        include "mtkplay.asm"
        ld hl,song : call mtk_init
        xor a      : call mtk_start
        ; once per frame, from your H.TIMI hook:
        call mtk_frame
        ; a laser on channel C:
        ld a,10 : ld b,61 : ld c,2 : call mtk_sfx
song:   incbin "mysong.mtk"

There's also an example cartridge: it plays the demo song, and keys 1–7 fire sound effects.

MSXTRACK is written in Z80 assembly. See the README for the full manual, the effect list and the song file format.
